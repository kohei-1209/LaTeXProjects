    \section{目的}
        本実験では、大腸菌からプラスミドを抽出し、そのプラスミドを、同じ複製起点のプラスミドをもつ大腸菌、及び異なる複製起点のプラスミドをもつ大腸菌に加え、形質転換体の数の計測を行った。また、抽出したプラスミドを制限消化し、電気泳動により未処理のプラスミドとの違いを確認した。本実験を通じて、微生物を取り扱う上での基本的な操作と法令、及び形質転換の原理、不和合性、制限修飾系について学んだ。

    \section{方法}
        本節では、本実験で行った大腸菌の形質転換とプラスミドDNAの制限消化について、詳細な手順を述べる。

        \subsection{大腸菌の形質転換}
            本実験では、プラスミドpMWK1257を抽出、精製し、それをプラスミドpBR322またはpMW118を有するコンピテントセルに加え、形質転換させた。形質転換体をカナマイシンを含む培地で培養することで、異なるプラスミド同士の和合性、不和合性について調べた。

            \subsubsection{プラスミドpMWK1257の抽出と精製 (1日目)}
                \begin{enumerate}
                    \item プラスミドpMWK1257を有する\textit{E.coli} DH5 $\alpha$株の一晩培養液 1 mLを1.5 mLマイクロチューブに移し、室温、10,000 rpmで1分間だけ遠心した。
                    \item 上清を捨て、チューブに200 $\mu$Lの再懸濁バッファー mP1を加え、ボルテックスで懸濁した。
                    \item チューブに200 $\mu$Lの溶解バッファー mP2を加え、10回ほどゆっくりと転倒混和し、室温で2分間だけ静置した。
                    \item チューブに300 $\mu$Lの中和バッファー mP3を加え、10回ほど転倒混和した。
                    \item チューブを13,000 rpmで5分間だけ遠心した。
                    \item FastGene\texttrademark{} mPカラムを2 mLコレクションチューブにセットした。
                    \item 手順5.で得られた上清をmPカラムに移し、13,000 rpmで1分間だけ遠心した。
                    \item mPカラムを一度取り外し、2 mLコレクションチューブに入ったろ液を捨て、カラムをコレクションチューブに再びセットした。
                    \item mPカラムに600 $\mu$Lの洗浄バッファー mP5を加え、13,000 rpmで1分間だけ遠心した。
                    \item 同様にろ液を捨て、再び13,000 rpmで2分間だけ遠心した。
                    \item カラムを新しい1.5 mLマイクロチューブにセットした。
                    \item メンブレンの中央に50 $\mu$Lの溶出バッファー mP6を加え、2分間だけ静置した。
                    \item チューブを13,00 rpmで2分間だけ遠心し、プラスミドを溶出させた。
                    \item 溶出させたプラスミドが入ったチューブは2日目まで保存した。
                \end{enumerate}

            \subsubsection{プラスミドpBR322またはpMW118を有するコンピテントセルの作製 (1日目)}
                \begin{enumerate}
                    \item プラスミドpBR322またはpMW118を有する\textit{E.coli} DH5 $\alpha$株を2時間培養した。
                    \item 各プラスミドを有する大腸菌の培養液を1.5 mLずつ別々の1.5 mLマイクロチューブに分注し、4 $^\circ$C、10,000 rpmで1分間だけ遠心した。
                    \item 上清を捨て、菌体が入った各チューブに氷冷した0.1M $\mathrm{CaCl_2}$溶液を1 mLずつ加え、よく懸濁した。
                    \item 各チューブを4 $^\circ$C、10,000 rpmで1分間だけ遠心した。
                    \item 上清を捨て、各チューブに氷冷した10\% グリセリン含有 0.1M $\mathrm{CaCl_2}$溶液を100 $\mu$Lずつ加え、よく懸濁した。
                    \item 各チューブを-80 $^\circ$Cで2日目まで保存した。
                \end{enumerate}

            \subsubsection{コンピテントセルの形質転換と培養 (2日目\&3日目)}
                \begin{enumerate}
                    \item 2.1.2節で作製したプラスミドpBR322またはpMW118を有するコンピテントセルの溶液 100 $\mu$Lに、2.1.1節で抽出したプラスミドpMWK1257の溶液を5 $\mu$Lずつ加えた。
                    \item 氷中に30分間静置した後、42 $^\circ$Cのヒートブロックに45秒間つけ、その後すぐに氷中に移し、2分間静置した。
                    \item 1 mLのLB培地を各チューブに加え、37 $^\circ$Cで30分間静置培養した。
                    \item 2枚のカナマイシン含有LB寒天培地に、各形質転換体培養液を100 $\mu$Lずつ塗布した。
                    \item 37 $^\circ$Cのインキュベーターで一晩培養し、3日目まで保存した。
                    \item 3日目に各形質転換体のコロニー数を計測した。
                \end{enumerate}

        \subsection{プラスミドDNAの制限消化}
            本実験では、プラスミドpMWK1257をEcoRIによって制限消化した。未処理のプラスミドと制限消化済みのプラスミドを電気泳動して、それらの分子量を比較することで、制限酵素によるプラスミドの消化について調べた。

            \subsubsection{EcoRIによるプラスミドpMWK1257の制限消化 (2日目)}
                \begin{enumerate}
                    \item 1.5 mLマイクロチューブに入ったEcoRI溶液 6 $\mu$Lに、2.1.1節で抽出したプラスミドpMWK1257の溶液 4 $\mu$Lを加えた。
                    \item 37 $^\circ$Cのインキュベーターで10分間静置した。
                \end{enumerate}

            \subsubsection{アガロースゲル電気泳動 (2日目 \& 3日目)}
                \begin{enumerate}
                    \item EcoRIで制限消化したプラスミドpMWK1257の溶液が入った1.5 mLマイクロチューブに、色素混合液 5 $\mu$Lを加えた。
                    \item パラフィルム上で、未処理のプラスミドpMWK1257の溶液 4 $\mu$Lと色素混合液 2 $\mu$Lを混合した。
                    \item また、$\lambda$-Hind III分子量マーカー 4 $\mu$Lと色素混合液 2 $\mu$Lをパラフィルム上で混合した。
                    \item 手順1-3.で調製した溶液の全量をアガロースゲルの別々のレーンにロードした。
                    \item 100Vで30分間通電し、電気泳動を行なった。
                    \item 電気泳動後、ゲルを取り出して、GelRed液に20分間浸して染色した。
                    \item 染色後、ゲルを紫外線イルミネーターで観察したところ、バンドが薄かったため、再度GelRed液で24時間染色した。
                    \item 染色後、ゲルを紫外線イルミネーターで観察した。
                \end{enumerate}
